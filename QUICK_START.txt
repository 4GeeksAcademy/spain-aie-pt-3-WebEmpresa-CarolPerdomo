┌─ 🎯 GUÍA DE USO RÁPIDO ────────────────────────────────────────────────────┐
│                                                                               │
│  1️⃣  VISUALIZAR PROVEEDORES                                                 │
│      └─ La tabla se carga automáticamente cuando abres la interfaz           │
│      └─ Puedes ver: Nombre, País, Categoría, Tarifa, Estado, Renovación     │
│                                                                               │
│  2️⃣  FILTRAR PROVEEDORES                                                    │
│      └─ País: Selecciona "Spain" o "USA"                                     │
│      └─ Categoría: Selecciona cualquiera de 9 tipos de servicio              │
│      └─ Los filtros se aplican automáticamente                               │
│                                                                               │
│  3️⃣  CREAR NUEVO PROVEEDOR                                                  │
│      └─ Haz clic en botón "➕ Nuevo Proveedor"                               │
│      └─ Rellena los campos (obligatorios marcados con *)                     │
│      └─ Categorías: Selecciona múltiples opciones (Ctrl+Click)              │
│      └─ Haz clic en "Registrar"                                              │
│      └─ El proveedor aparecerá en la tabla                                   │
│                                                                               │
│  4️⃣  EDITAR TARIFA MENSUAL                                                  │
│      └─ Haz clic en el ícono ✏️ (lápiz) en la columna "Tarifa Mensual"      │
│      └─ Modifica el valor numérico                                           │
│      └─ Haz clic en 💾 (guardar) para confirmar                              │
│      └─ La tarifa se actualiza en la API automáticamente                     │
│                                                                               │
│  5️⃣  CAMBIAR ESTADO (Activo/Suspendido)                                     │
│      └─ Haz clic en 🔒 (si está activo) o 🔓 (si está suspendido)           │
│      └─ El estado cambia inmediatamente                                      │
│      └─ Los proveedores suspendidos aparecen más grises en la tabla         │
│                                                                               │
│  6️⃣  ELIMINAR PROVEEDOR                                                     │
│      └─ Haz clic en el ícono 🗑️ (papelera)                                  │
│      └─ Confirma en el popup de seguridad                                    │
│      └─ El proveedor se elimina de la base de datos                          │
│                                                                               │
└───────────────────────────────────────────────────────────────────────────────┘
