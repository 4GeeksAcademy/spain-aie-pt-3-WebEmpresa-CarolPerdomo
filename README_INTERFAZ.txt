  🐛 SOLUCIÓN DE PROBLEMAS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ PROBLEMA: "No se carga la interfaz"
✅ SOLUCIÓN:
   1. Abre la consola (F12) → "Console"
   2. Busca mensajes rojos con errores
   3. Recarga la página (Ctrl+R o Cmd+R)
   4. Espera 3-5 segundos

❌ PROBLEMA: "Connection refused"
✅ SOLUCIÓN:
   • Verifica que el puerto 8000 (API) está abierto
   • Verifica que el puerto 3000 (Web) está abierto
   • Reinicia los servidores si es necesario

❌ PROBLEMA: "Los cambios no se guardan"
✅ SOLUCIÓN:
   • Abre la consola del navegador (F12)
   • Verifica que no hay errores
   • Recarga la página

❌ PROBLEMA: "404 Not Found"
✅ SOLUCIÓN:
   • Verifica que la URL es correcta
   • Asegúrate de usar la URL completa con https://
