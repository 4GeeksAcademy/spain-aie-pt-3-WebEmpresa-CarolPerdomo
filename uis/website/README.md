# Nexova Public Website

Public-facing corporate website for Nexova Solutions. It presents the company's three service lines, regional presence, talent contact, and company contact details.

## Run locally

```bash
npm install
npm run dev
```

Open <http://localhost:3000>. Production checks:

```bash
npm run lint
npm run build
```

This app is an independent Next.js project. No backend is configured; future API services belong under the monorepo's `/services` directory.
