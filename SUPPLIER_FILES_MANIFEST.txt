DATA MODEL
================================================================================

SUPPLIER DOCUMENT (TinyDB):

{
  "id": 1,                                      // Auto-incremented by TinyDB
  "name": "TechSolutions España",               // Required, non-empty string
  "country": "spain",                           // Optional, default: "spain"
  "categories": ["Software", "Services"],       // Required, array, min 1 item
  "daily_rate": 450.5,                          // Required, > 0
  "status": "active",                           // Optional, default: "active"
  "updated_at": "2024-11-14T14:51:17.962387"   // ISO 8601 timestamp
}

VALID VALUES:

  Status (Enum):
    • "active"
    • "inactive"

  Categories (Enum):
    • "Software"
    • "Hardware"
    • "Services"
    • "papeleria"
    • "cafeteria"

  Country:
    • "spain" (only supported value currently)

  Daily Rate:
    • Positive number (> 0)
    • Decimals supported
    • Currency: Euro (€)
